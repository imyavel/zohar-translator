# Правила оформления перевода

> **Это образец `formatting_rules` для пары иврит+арамит → русский
> (Книга Зоар).** Для своего корпуса перепиши правила под свою
> пунктуацию, кавычки, сноски, нумерацию. Файл читается
> translator-агентом как часть промпта.
>
> Этот файл — обязательный к применению при каждом переводе.

---

## 1. Нумерация параграфов

- Номер параграфа — **абсолютный номер из Сулама** (не порядковый внутри статьи).
- Формат: `N) Текст параграфа...`
- Между параграфами — одна пустая строка.

**Пример:**

```
237) Заповедь десятая — возлагать тфилин...

238) Открыл и сказал: "Голова твоя на тебе, как Кармель"...
```

**НЕ правильно:**

```
## Параграф 237

Заповедь десятая — возлагать тфилин...
```

---

## 2. Заголовок статьи

- Первая строка файла: `# Статья NN. Название на русском`.
- Транслит ивритского/арамейского названия в скобках — **НЕ давать**
  (правило пересмотрено в v108 — см. §7 ниже).
- Исключение: если название по традиции — устойчивая аббревиатура
  с гершаим (напр. `ТО"В`, `ЗО"Н`), её можно оставить в имени.
- Пустая строка после заголовка, затем первый параграф.

**Пример:**

```
# Статья 30. Десятая заповедь

237) Заповедь десятая — возлагать тфилин...
```

---

## 3. Цитаты из Писания

- Цитаты из Танаха заключать в кавычки-ёлочки.
- После цитаты — ссылка в скобках: (Книга, глава:стих).
- Названия книг в ссылке — транслит кириллицей, кроме пяти
  русифицированных:
  - שיר השירים → **Песнь Песней** (не «Шир hа-Ширим»)
  - תהלים → **Псалмы** (не «Теhилим»)
  - משלי → **Притчи** (не «Мишлей»)
  - שופטים → **Судьи** (не «Шофтим»)
  - מלכים → **Цари** (не «Мелахим»)

**Пример:**

```
"Голова твоя на тебе, как Кармель" (Песнь Песней, 7:6)
"И сказал Господь Моше" (Шмот, 12:1)
```

---

## 4. Пояснение Сулама

- Если параграф содержит пояснение Сулама (начинается с "פירוש"),
  начать с маркера: `Пояснение.` (без жирного, без "сказанного").
- Текст Зоар и «Пояснение.» разделены **пустой строкой**
  (чтобы визуально не сливались).

---

## 5. Выделение цитат

- **Жирным** помечать ровно те фрагменты, что в Source JSON
  (`Source/Sulam_on_Zohar/*.json`) обёрнуты тегом `<b>...</b>`.
  Не расширять жирный за пределы этих обёрток.
- Если внутри `<b>`-обёрнутого фрагмента встречается цитата из Танаха —
  она оформляется как ***жирный курсив*** (курсив поверх уже жирного
  блока).
- Цитаты НЕ из Танаха, Талмуда и т. п. в комментарии Сулам — **жирный**.
- Цитаты из Танаха в комментарии Сулам — *курсив*.

Различие: цитаты из Танаха распознаются (а) по ссылке-источнику
в скобках после закрывающей кавычки, напр. (Берешит 1:27);
(б) при отсутствии ссылки — по узнаваемой формулировке стиха.
Все остальные «кавычки» в комментарии — внешние цитаты
(Зогар, Эц Хаим, Тикуней Зогар, и т. п.), их размечаем жирным
по правилу выше.

**Пример параграфа:**

```
237) **Заповедь десятая — возлагать тфилин и т. д.:**
заповедь десятая — возлагать тфилин, и [об этом] сказано
*«И сотворил Элоким человека в целем Его»* (Берешит 1:27),
ибо в тайне сказанного **«Има одолжила дочери одежды свои»**
включилась Има в Малхут.

Пояснение. Благодаря заповеди Има включилась в Малхут в тайне
*«Сотворим человека в образе нашем»* (Берешит 1:26).
```

В этом примере:
- `**Заповедь десятая — возлагать тфилин и т. д.:**` —
  инципит Зогара (жирный, обёрнут `<b>` в Source).
- `*«И сотворил Элоким человека в целем Его»*` (Берешит 1:27) —
  цитата Танаха в комментарии (курсив, опознана по ссылке).
- `**«Има одолжила дочери одежды свои»**` —
  внешняя цитата без танаховой ссылки (жирный).
- `*«Сотворим человека в образе нашем»*` (Берешит 1:26) —
  цитата Танаха в комментарии (курсив).

---

## 6. Общие правила

- Формат файла: Markdown (.md), кодировка UTF-8.
- Без лишних пустых строк (ровно одна между параграфами).
- Без горизонтальных линий (---) между параграфами.

---

## 7. Транслитерация (v108)

- Полные ивритские/арамейские фразы и цитаты транслитерировать
  **НЕ нужно**. Давать только русский перевод + ссылку на источник
  в скобках.
- Транслит — только для **ключевых каббалистических терминов**
  при **первом** упоминании в статье (с пояснением в скобках):
  `хесед (милость)`, `Нуква (женское)`, `келим (сосуды)`.
  Далее — только русский/транслит без повторных пояснений.
- **Оставлять** транслит:
  - аббревиатуры с гершаим: `АВА"Я`, `ЗО"Н`, `ГА"Р`, `ХаБа"Д`;
  - имена собственные: `Авраhам`, `Моше`, `Йосеф`, `Йерушалаим`;
  - устойчивые каббалистические термины одним словом/оборотом:
    `Зеир Анпин`, `Арих Анпин`, `ситра ахра`, `масах`, `цимцум`;
  - тетраграмматон — всегда переводить как «Господь» (S005).
- **Убирать** транслит:
  - полные цитаты из Танаха/Зоара после русского перевода;
  - устойчивые идиомы-фразы (3+ слов) в скобках после перевода;
  - заголовки Сулам с `и т. д. (транслит)` — оставлять `и т. д.`;
  - заголовки статей с транслитом в конце.
